# PvZ iOS Port с хардмодом

Этот репозиторий — форк [PvZ-Portable](https://github.com/wszqkzqk/PvZ-Portable): полная
кроссплатформенная перереализация движка Plants vs Zombies GOTY. Ассеты **не** включены —
они берутся из вашей легальной копии игры.

Добавлено:

- переключатель **Hard Mode** в меню настроек (выключен по умолчанию);
- сохранение состояния переключателя в реестре приложения;
- множители сложности: HP зомби, скорость, количество зомби в волнах;
- все параметры читаются из `properties/pvz-portable.xml`, поэтому их можно менять
  **без пересборки IPA**.

> Только для личного пользования. Не распространяйте файлы `main.pak` и `properties/`
> из вашей копии игры.

## Сборка iOS через GitHub Actions

1. Создайте форк этого репозитория на GitHub.
2. Залейте изменения в ветку `main` (или другую ветку).
3. Откройте вкладку **Actions** → **CI build** → **Run workflow**.
4. После завершения скачайте артефакт **pvz-portable-ios** (`pvz-portable-ios-arm64.ipa`).

CI уже содержит job `build-ios` на `macos-latest`, собирающий **unsigned IPA** для iOS 16.4+ (arm64).

Для быстрой проверки на Windows можно скачать артефакт **pvz-portable-windows-msvc-x64** из того же
запуска CI — он позволяет проверить совместимость ассетов и работу хардмода без iOS-устройства.

## Установка на iOS

Unsigned IPA можно установить одним из способов:

- **TrollStore** — если поддерживаемая версия iOS, подпись не истекает;
- **AltStore / SideStore** — переподпись раз в 7 дней при бесплатном Apple ID;
- **Xcode** (на Mac) — free Apple ID, тоже 7 дней.

После установки:

1. Откройте приложение **Файлы** (или Finder → «Общий доступ к файлам»).
2. Скопируйте `main.pak` и папку `properties/` в папку документации **PvZ Portable**.
3. Запустите игру.

## Ассеты версии 1.0.0.1051

Оригинальный релиз 1.0.0.1051 **не совместим напрямую**: в нём анимации лежат в виде
скомпилированных 32-битных блобов (порт ожидает XML), а часть GOTY-ресурсов отсутствует.
Для подготовки ассетов есть скрипт:

```bash
python3 hardmode/prepare_assets.py "C:/path/to/pvz-1.0.0.1051-en/1.0.0.1051 EN" prepared/
```

Он создаст в `prepared/` патченный `main.pak`, в котором:

- скомпилированные `.reanim` сконвертированы в XML;
- добавлен минимальный `particles/IceTrail.trail`;
- добавлены недостающие изображения (существующие файлы переиспользуются, остальные
  указывают на `blank`);
- исправлен регистр имени файла шрифта `briannetod12.txt`.

Рядом с этим `main.pak` положите оригинальную папку `properties/` из игры и файл
`properties/pvz-portable.xml` с настройками хардмода. Именно `main.pak` + `properties/`
нужно скопировать в Documents приложения на iOS.

Дополнительно в движок внесено исправление: `DefinitionReadCompiledFile()` теперь читает
скомпилированные definition-файлы через `p_fopen()`, то есть из `main.pak`, а не только с диска.

## Настройка хардмода без пересборки

Файл `properties/pvz-portable.xml`:

```xml
<Properties>
    <String id="OPTIONS_HARD_MODE">Hard Mode</String>

    <Double id="HARDMODE_HEALTH_MULT">1.6</Double>
    <Double id="HARDMODE_SPEED_MULT">1.15</Double>
    <Double id="HARDMODE_POINTS_MULT">1.35</Double>

    <Integer id="OPTION_DLG_HARDMODE_CHECKBOX_Y">70</Integer>
    <Integer id="OPTION_DLG_HARDMODE_LABEL_Y">93</Integer>
</Properties>
```

Значения:

- `HARDMODE_HEALTH_MULT` — множитель HP зомби (тело, шлем, щит, полёт);
- `HARDMODE_SPEED_MULT` — множитель скорости передвижения;
- `HARDMODE_POINTS_MULT` — множитель «очков зомби» в волне, то есть плотности волн;
- `OPTIONS_HARD_MODE` — подпись переключателя (можно перевести на русский);
- `OPTION_DLG_HARDMODE_CHECKBOX_Y` / `..._LABEL_Y` — положение чекбокса и подписи,
  если они перекрывают другие элементы в вашей версии ассетов.

Хардмод применяется ко всем режимам, кроме puzzle-режимов. Переключатель вступает
в силу для заново заспавненных зомби и волн; текущую начатую волну лучше перезапустить.

## Что проверить в первую очередь

1. Совместимость `main.pak` от 1.0.0.1051 (Windows-сборка из CI).
2. Отображение чекбокса в меню настроек и его сохранение после перезапуска.
3. Реальную сложность: при необходимости подкрутить три множителя в XML.
4. Стабильность на iOS после сайдлоада.
